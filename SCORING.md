# K-BIT Scoring System

The K-BIT score is a pre-biopsy clinical risk score for major bleeding after kidney biopsy.

## Scoring criteria

| Variable | Category | Points |
|---|---|---:|
| Age | <50 years | 0 |
|  | 50–69 years | 1 |
|  | 70–89 years | 3 |
| Pre-biopsy diagnosis | Chronic glomerulonephritis / Proteinuria / Nephrotic Syndrome | 0 |
|  | IgA Vasculitis | 1 |
|  | Interstitial Nephritis / Other kidney diseases / Other collagen diseases | 2 |
|  | RPGN / AAV / SLE / MM, MGUS / Amyloidosis / Acute Kidney Injury | 3 |
| BMI | ≥22 kg/m² | 0 |
|  | 18.5–<22 kg/m² | 1 |
|  | <18.5 kg/m² | 2 |
| CCI | 0 | 0 |
|  | ≥1 | 1 |

## Score categories

- **Very-Low:** 0–2
- **Current-practice-equivalent:** 3
- **Moderate-to-High:** 4–8

## Interpretation

In the simulation, discharge of patients with a K-BIT score of 3 or lower was associated with a major bleeding risk approximately equivalent to that under current practice.

## Notes

The K-BIT score is intended for research and informational purposes and should be interpreted together with the accompanying study and clinical judgment.
